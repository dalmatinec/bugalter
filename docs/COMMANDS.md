# Команды бота

`<…>` — обязательно, `[…]` — необязательно. `@код` — подразделение (в рабочей группе подставляется само).
Период: `сегодня`, `вчера`, `неделя`, `месяц`, `прошлый_месяц`, `ДД.ММ`, `ДД.ММ-ДД.ММ`, `ГГГГ-ММ-ДД..ГГГГ-ММ-ДД`.

## Сотрудник (личка)

| Команда / кнопка | Что делает |
|---|---|
| `/start inv_…` (ссылка-приглашение) | подключение; после него появляется меню. Незнакомым людям бот не отвечает |
| 📊 Моя работа · `/my_work [прошлый\|период]` | операции и итоги по видам работ со статусами и суммами |
| 💰 Мой расчёт · `/my_salary [прошлый\|п12\|период]` | расчёт с расшифровкой: работа по ставкам, премии, удержания, выплаты, остаток |
| 📦 Мои товары · `/my_stock` | что числится на сотруднике (кнопка появляется, когда ему впервые выдали товар) |
| 💸 Попросить аванс · `/request_payout <сумма> [комментарий]` | любая сумма. Просьба приходит владельцу, он нажимает Одобрить, и бот сразу записывает аванс и пишет сотруднику. Аванс потом вычитается из зарплаты |
| 🧾 Мои выплаты · `/my_payouts` | история выплат |

## Рабочая группа

| Команда | Что делает |
|---|---|
| `#тег количество` | отчёт о работе: `#доставка 3`, несколько в одном сообщении `#фасовка05 20 #фасовка1 5`, можно добавить `вчера` или `14.10` и комментарий. Тег = название работы без пробелов и знаков, виден в Работах и ценах. В группе сотрудника записывается на него, в общей группе на того, кто написал. Одна карточка на весь отчёт, подтверждение одной кнопкой. Бот должен быть администратором группы |
| Отчёт столбиком | строка с названием, под ней `5х05`, `10х1` (количество х вес): это 5 шт работы «Название 0.5» и 10 шт «Название 1». Несколько названий в одном сообщении. Одной строкой: `Крам факт 1 13` значит 13 шт работы «Крам факт 1», без числа 1 шт. Обычные сообщения бот не трогает |
| `/bind` | привязать группу кнопками (бот спрашивает сам, когда его добавляют в группу) |
| `/op` | мастер: сотрудник → работа → количество (+ `#заказ`, дата, комментарий) → черновик → «Отправить» |
| `/op <сотрудник> <работа> <кол-во> [#заказ] [вчера\|ДД.ММ] [*коэффициент] [комментарий]` | быстрый ввод сразу на подтверждение; для `percent` количество — сумма заказа |
| кнопки ✅/❌ на карточке | подтвердить (начислить) / отклонить: владелец и операторы (можно оставить только владельцу в Настройках). Сотрудник свою работу не подтверждает |
| `/pending`, `/ops [период]`, `/op_info <№>` | ожидающие, сводка, карточка |
| `/cancel_op <№> <причина>` | отмена; для подтверждённой — сторно (право `work.cancel`) |
| `/reject_op <№> <причина>` | отклонить с причиной |
| `/receive <артикул> <кол-во> [ед.] [cost=цена за ед.] [cur=валюта] [комм.]` | поступление на склад, создаёт партию |
| `/issue <сотрудник> <артикул> <кол-во> [ед.]` | выдача → «в пути» → получатель жмёт «Получено» |
| `/move <от> <кому> <артикул> <кол-во> [ед.]` | передача между сотрудниками (через «в пути») |
| `/send <подразделение> <артикул> <кол-во> [ед.]` | перемещение на склад другого подразделения |
| `/return <сотрудник> <артикул> <кол-во> [ед.]` | возврат на склад |
| `/sold <сотрудник> <артикул> <кол-во> [ед.] [#заказ]` | отгрузка клиенту с товара на руках |
| `/writeoff <артикул> <кол-во> [ед.] <причина> [emp=код]` | списание со склада или с сотрудника |
| `/inv <склад\|сотрудник> <артикул> <факт> [ед.]` | инвентаризация; разница → расхождение |
| `/case <№> company` · `/case <№> employee cost` · `/case <№> employee <цена> [валюта] <основание>` | решение по расхождению (cost — по себестоимости партий) |
| `/stock [сотрудник]`, `/transit`, `/cases`, `/products` | остатки (в личке — с себестоимостью), товар в пути, расхождения, номенклатура |
| `/batches <артикул>` (личка) | партии: дата, цена, пришло, осталось |

## Деньги (личка, руководитель / бухгалтер)

| Команда | Что делает |
|---|---|
| `/bonus`, `/penalty`, `/deduct <сотрудник> <сумма> [валюта] [@подр] <основание>` | выписать документ; проводится после подписи |
| `/adjs` · кнопки «Подписать / Отклонить» | документы на подпись |
| `/adj_cancel <№> <причина>` | отмена (проведённый — сторно) |
| `/payout <сотрудник> <сумма> [валюта] [аванс\|зп\|запрос] [@подр] [комментарий]` | регистрация выплаты |
| `/payouts` · кнопка «Подтвердить выплату» | неподтверждённые выплаты |
| `/payout_cancel <№> <причина>` | отмена выплаты (проведённой — сторно) |
| `/requests` | запросы выплат сотрудников: одобрить → создаётся выплата |
| ⚙️ Управление → 📊 Отчёты | Срок 1, Срок 2, месяц, квартал или свои даты: по каждому сотруднику заработано, премии, штрафы, выдано авансом и зарплатой, сколько должны сейчас. Кнопка Скачать Excel |
| ⚙️ Управление → 📦 Склад | по каждому товару: сколько пришло, выдано и вернули, сколько на складе и у каждого сотрудника. Кнопки Приход, Выдать, Принять готовое (сотрудник сдал готовый товар), Израсходовано (сырьё ушло в работу), Возврат, История и подсказка Как работать со складом. Выданный товар записывается на сотрудника, когда он нажмёт Получено |
| ⚙️ Управление → 💸 Выплаты | аванс любой суммой; зарплата с вычетом аванса или без (тогда он вычтется в следующую зарплату); просьбы об авансе |
| `/balance <сотрудник> [прошлый\|п12\|период]` | подробный расчёт |
| `/periods`, `/period <№>` | периоды и зафиксированные итоги |
| `/period_close <№>` | закрыть период (при неподтверждённых операциях — предупреждение и кнопка) |
| `/period_reopen <№> <причина>` | переоткрыть (только владелец) |
| `/report emp\|dept\|ops\|stock\|moves\|payouts\|adj\|debts … [период] [xlsx\|csv]` | отчёты и выгрузка |

## Управление (личка)

Кнопка «Управление» или команда `/admin`. Сотрудники, работы и цены, группы, доплаты, товары, настройки,
доступ, филиалы, журнал изменений — всё это кнопками и короткими ответами, без текстовых команд.
Подробно: docs/DEPLOY.md, шаг 7.

### Сотрудники и роли

Сотрудник заводится по **должности** (Курьер, Фасовщик). Имя не нужно: когда человек откроет ссылку,
его ник и Telegram ID увидит только владелец в карточке; все остальные видят только должность.
Две одинаковые должности различаются номером: «Курьер», «Курьер 2».

| Роль | Права |
|---|---|
| Владелец | всё. Владельцев может быть несколько: `OWNER_TELEGRAM_IDS=111,222` в `.env` |
| Работник (без роли) | своё меню в личке: работа, расчёт, выплаты, запрос выплаты; отчёт тегами в своей группе |
| Оператор | ещё проверяет и подтверждает кнопкой отчёты сотрудников, вводит работу и склад |
| Бухгалтер | выплаты, авансы, просьбы об авансе, премии и штрафы, отчёты. В Управлении видит только Выплаты. Если одобрил аванс он, а выплаты подтверждает владелец, владельцу придёт кнопка подтверждения |
| Кладовщик | раздел 📦 Склад в Управлении: приход, выдача сотруднику, возврат, остатки и история |
| Руководитель | всё сразу: ставки, премии и штрафы, выплаты, склад, отчёты. Подтверждает работу и выплаты, только если владелец разрешил в Настройках |

Роль Администратор осталась в системе, но кнопкой не предлагается. В Управлении каждый видит только те
разделы, на которые у него есть права.

В карточке сотрудника: **💼 Оклад** (фиксированная зарплата в месяц, половина начисляется сама в каждый день
зарплаты), **💸 Выплаты**, **💰 Своя цена**, **✏️ Должность**. Уволенного можно **♻️ Вернуть** или **🗑 Удалить**
(только владелец): без истории стирается полностью, с историей пропадает из списков, а проведённые суммы
остаются в отчётах.

**💾 Бэкап** (Настройки, только владелец): скачать копию базы, сделать новую, восстановить из присланного файла.
